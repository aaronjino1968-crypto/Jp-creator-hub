# JP Creator Hub

A lightweight, responsive creator landing page for JP Video Diary. It does not embed or host videos.

## Files
- `index.html` — complete site (HTML, CSS, and JavaScript in one file).

## Publish from an Android phone using GitHub Pages
1. Download and extract `JP-Creator-Hub.zip` on your phone.
2. Open GitHub in Chrome and sign in to the account that owns the repository `Jp-creator-hub`.
3. Open the `Jp-creator-hub` repository.
4. Tap **Add file** → **Upload files** (if the mobile layout hides it, use Chrome's menu → **Desktop site**).
5. Upload `index.html` to the repository's root. If an `index.html` already exists, replace it with this version.
6. Commit the changes.
7. In the repository, open **Settings** → **Pages**. Make sure GitHub Pages is configured to deploy from the `main` branch and `/ (root)` (or keep the repository's existing working source setting).
8. Wait for the deployment to finish, then open:
   https://aaronjino1968-crypto.github.io/Jp-creator-hub/
9. Test all buttons on the published page, including Share Website and Copy Website Link.

## Important published URL note
The JavaScript's `PUBLISHED_URL` is set to `https://aaronjino1968-crypto.github.io/Jp-creator-hub/`, based on the published URL provided for this site. If the final GitHub Pages address is different, change that one constant near the bottom of `index.html` to the exact final URL, then commit the change again.

## Share with friends
Open the published website in Chrome, tap **Share Website**, and choose an app. If the share menu isn't available, use **Copy Website Link** and paste the URL into WhatsApp or another app.
